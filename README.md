# アクスタジェネレーター

画像をアップロードすると、絵の形に沿ってカットしたアクリルスタンドを3Dで作り、GLBファイルとして書き出せるツールです。

## 使い方

`index.html` をブラウザで開くだけで使えます（インストール不要）。

1. 「画像を選ぶ」で画像を読み込む（画面にドロップしてもOK）。背景が透明なPNGがいちばんきれいです
2. カット余白・サイズ・板の厚み・白版・質感・台座を調整する
3. 「3Dデータを保存」でGLBを書き出す

## できること

右メニューは「本体／台座／書き出し」のタブ切り替え。アイコンにマウスを乗せると説明が出ます。


- 絵の輪郭に沿った自動カット（余白mm指定・穴埋め・なめらかさ調整）
- JPGなど透明でない画像の背景を自動で削除
- 実物と同じ層構造：アクリル板 → 裏刷りの絵柄 → 白版
  - 白版：絵柄どおり / 少し内側 / 板全体（ベタ白） / なし
- アクリルの質感：屈折率1.49、ツヤ〜すりガラス、ふちの色味、光の虹色
- 台座：だ円 / 角丸 / まる / **アップロードした画像の形**、クリア・白・黒、差し込み穴つき（左右・前後の位置調整）
  - 画像台座はその形でカットし、クリアなら裏刷り、白・黒なら上面に印刷
- 書き出し
  - GLB（実寸・mm基準）
  - 入稿用データ一式：印刷画像・白版（K100）・カットパスSVG
  - プレビューPNG

## 仕組み

1ファイルのHTMLで、3D表示に [three.js](https://threejs.org/) を使っています（CDNから読み込み）。
